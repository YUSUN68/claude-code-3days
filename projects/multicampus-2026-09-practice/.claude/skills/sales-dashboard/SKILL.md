# 월별 매출 → 통합 엑셀 → 대시보드

수강생이 새 달 매출 파일을 주거나 "매출 통합·대시보드 다시 만들어줘"라고 하면 이 순서대로 진행한다.
한 번의 실행으로 **통합 엑셀**(통합 데이터·월별 요약·부서별 요약·정리 기록)과 **HTML 대시보드**가 함께 만들어지고, 스크립트가 원본 합계와 결과를 대조해 검증까지 한다.

- 스크립트: [scripts/build_sales.py](scripts/build_sales.py) — `check`(점검), `add`(새 달 파일 넣기), `build`(통합+대시보드)
- 대시보드 틀: [templates/dashboard.html](templates/dashboard.html) — 루트 `CLAUDE.md`의 진초록 디자인. 숫자는 스크립트가 채운다.
- 기본 원본 폴더: `03_매출데이터` (다른 폴더면 `--folder`로 지정)

## 실행 방법

실습 폴더(루트)에서 가상환경 Python으로 실행한다. 경로는 `.setup-status.md`에 적힌 것을 확인해서 쓴다.

```powershell
& ".venv\Scripts\python.exe" -X utf8 ".claude\skills\sales-dashboard\scripts\build_sales.py" check
```

- 콘솔에서 한글이 깨져 보이면 `--report <스크래치 폴더>\sales_report.txt` 를 붙여 UTF-8 파일로 받고 그 파일을 읽는다 (korean-safe-windows 스킬 3장).
- 종료 코드: `0` 성공 · `2` 멈춤(확인 필요) · `3` 만든 뒤 검증 실패.

## 진행 순서

### 1. 받은 파일 확인

수강생이 새 파일을 줬다면 경로와 연월부터 확인한다.

- 파일 이름에 연월이 있으면(`2026년_09월`, `2026-09`, `202609`) 그걸 쓴다.
- 없으면 시트 내용을 열어보고, 그래도 모르면 **"몇 년 몇 월 매출인가요?"** 라고 묻는다. 연월을 추측해서 정하지 않는다.

```powershell
& ".venv\Scripts\python.exe" -X utf8 ".claude\skills\sales-dashboard\scripts\build_sales.py" add "<받은 파일 경로>" --month 2026-09
```

- 원본은 그대로 두고, `03_매출데이터\2026년_09월_매출.xlsx` 처럼 **표준 이름으로 복사**한다.
- 같은 달 파일이 이미 있으면 멈춘다. 내용이 같으면 그냥 넘어간다. 다르면 "9월 파일이 이미 있어요. 새 파일로 바꿀까요?" 하고 물은 뒤, 수강생이 원할 때만 `--replace` 를 붙인다.
- 수강생이 이미 폴더에 직접 넣었다면 이 단계는 건너뛴다.

### 2. 점검 (`check`)

만들기 전에 반드시 점검 결과를 읽는다. 아래가 나오면 **만들지 말고 수강생에게 먼저 알린다.**

| 보고서 표시 | 뜻 | 할 일 |
|---|---|---|
| `[멈춤] … 7개 열을 모두 찾지 못했어요` | 처음 보는 열 이름 | 원본 첫 줄을 보여주고 어느 열이 부서·항목·거래처·담당자·매출액·비용·이익인지 확인한다. 확인되면 스크립트 `SYNONYMS`에 그 이름을 추가한다. |
| `[멈춤] … 단위가 원이 아니에요` | 천원·만원·USD 등 | 원 단위로 바꿀지 물어본다. 환율이나 배수를 임의로 정하지 않는다. |
| `[멈춤] 같은 달 파일이 둘 이상` | 최종본·수정본이 같이 있음 | 어느 파일을 쓸지 묻는다. 안 쓰는 파일을 지우지 말고, 이름을 바꾸거나 다른 폴더로 옮길지 물어본다. |
| `[멈춤] 매출 표가 있는 시트가 여러 개` | 시트가 여러 개 | 어느 시트인지 묻는다. |
| `[확인 필요] 중간에 빠진 달` | 예: 8월 다음에 10월 | 빠진 달 파일이 있는지 묻는다. 없어도 진행하자고 하면 `--allow-gap`. |
| `! … 매출액−비용≠이익` | 원본 계산이 안 맞음 | 원본 값을 그대로 두고 만든다. 결과 보고에 해당 행을 알린다. |
| `! 합계 줄로 보여서 뺐어요` / `빈칸` / `글자로 적힌 금액` | 자동 처리됨 | 결과 보고에 한 줄로 알린다. |

### 3. 만들기 (`build`)

```powershell
& ".venv\Scripts\python.exe" -X utf8 ".claude\skills\sales-dashboard\scripts\build_sales.py" build --note "교육용 가상 자료"
```

- `--note "교육용 가상 자료"` 는 **실습 폴더의 가상 자료일 때만** 붙인다. 수강생 회사의 실제 자료면 빼거나 수강생이 원하는 문구(예: `"사내 한정"`)를 넣는다.
- 폴더 안 **모든 달**을 다시 읽어 처음부터 만든다. 이전 통합 파일에 이어 붙이지 않으므로, 지난달 원본이 고쳐졌어도 반영된다.
- 파일 이름은 기간에 맞춰 정해진다: `2026년_01-09월_매출_통합.xlsx`, `2026년_01-09월_매출_대시보드.html`. 해가 넘어가면 `2026년_09월-2027년_02월_…` 형식이다.
- 같은 기간 결과물이 이미 있으면 새로 덮어쓴다(이전 내용은 Git 기록에 남는다).

### 4. 결과 확인

1. 보고서 끝에 `[검증 통과]` 가 있는지 본다. 스크립트는 통합 엑셀을 다시 열어 행 수·월별 합계·부서별 합계·요약 시트 수식 범위·대시보드 데이터를 원본과 대조한다. `[검증 실패]` 면 커밋하지 말고 원인을 확인한다.
2. 대시보드를 브라우저 창에서 열어 제목·기간·최근 달 문장이 맞는지, 차트가 그려지는지 한 번 본다.
3. `[이전 결과물]` 줄이 있으면(예: 9월을 추가해서 `01-08월` 파일이 남은 경우) **지우지 말고** 수강생에게 묻는다: "지난 기간(1~8월) 통합 파일과 대시보드는 그대로 둘까요, 정리할까요?" 기본은 그대로 둔다.

### 5. 커밋

루트 `CLAUDE.md`의 Git 자동 커밋 규칙을 따른다. 이 작업에서 바뀐 파일만 커밋한다(새로 복사한 원본, 통합 엑셀, 대시보드).

```
2026년 9월 매출 추가하고 1~9월 통합·대시보드 새로 만듦

03_매출데이터/2026년_09월_매출.xlsx: 받은 9월 매출 파일을 표준 이름으로 복사 (25행)
03_매출데이터/2026년_01-09월_매출_통합.xlsx: 9개월 225행 통합, 월별·부서별 요약 수식 포함
03_매출데이터/2026년_01-09월_매출_대시보드.html: 1~9월 데이터로 새로 만듦
원본 9개 파일 월별 합계와 통합 엑셀·대시보드 합계 일치 확인
```

## 수강생에게 보고하는 방법

결론부터, 짧게 알린다.

1. 무엇을 넣었는지: "9월 파일을 `03_매출데이터`에 넣었어요 (25건)."
2. 핵심 숫자: 전체 기간 매출액·이익률, 최근 달 매출과 전월 대비 증감 — **보고서에 찍힌 숫자만** 쓴다.
3. 결과 파일 두 개를 링크로 보여준다.
4. 확인할 점(`!` 줄)이 있으면 한 줄씩 알린다.
5. 커밋 번호와 메시지 첫 줄.

## 하지 않는 것

- 원본 매출 파일의 내용·이름을 바꾸거나 지우지 않는다. 새 파일은 **복사**만 한다.
- 보고서에 없는 숫자를 만들지 않는다. 매출액−비용≠이익인 행도 원본 값을 고치지 않는다.
- 단위 변환·연월 추정·시트 선택을 수강생 확인 없이 하지 않는다.
- 대시보드 디자인을 요청 없이 바꾸지 않는다. 디자인을 바꿔달라는 요청이면 `templates/dashboard.html` 을 고친다. 그러면 다음 달에도 바뀐 디자인으로 만들어진다.
- 수강생 회사 서식이 따로 있으면 그 서식을 우선한다(루트 `CLAUDE.md`).
