# 나의 위키

LLM(Claude)이 쓰고 관리하는 개인 지식 위키입니다.
안드레이 카르파시의 [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 아이디어를 한국어로 구현했습니다.

> 나는 자료를 고르고 질문한다. 정리·요약·링크·색인은 Claude가 한다.

## 폴더 구성

| 폴더/파일 | 역할 | 누가 쓰나 |
|---|---|---|
| `raw/` | 원본 자료 (기사, 논문, 메모, PDF, 이미지) | **나** |
| `wiki/` | 정리된 위키 페이지 | **Claude** |
| `wiki/index.md` | 전체 목차 | Claude |
| `wiki/log.md` | 작업 기록 | Claude |
| `CLAUDE.md` | Claude가 따르는 규칙 (스키마) | 함께 |

## 사용법

이 폴더에서 Claude Code를 열고 아래처럼 말하면 됩니다.

### 1. 자료 넣기 (수집)
1. 읽은 글, 논문, 메모 등을 `raw/` 폴더에 넣습니다. (`.md`, `.txt`, `.pdf` 등)
2. Claude에게:
   - `/ingest raw/파일이름.md`
   - 또는 "raw에 새로 넣은 자료 수집해 줘"

Claude가 요점을 말해 주고, 출처 요약 페이지를 만들고, 관련 인물·개념 페이지를 고치고, 목차와 기록을 갱신합니다.

### 2. 질문하기 (질의)
- `/query 질문 내용`
- 또는 그냥 "내 위키에서 ○○에 대해 정리한 거 알려줘"

좋은 답은 `wiki/analyses/`에 새 페이지로 저장할 수 있습니다.

### 3. 건강 검진 (점검)
- `/lint`
- 또는 "위키 점검해 줘"

모순, 고아 페이지, 빠진 링크, 더 찾아볼 주제 등을 찾아 줍니다.

## 함께 쓰면 좋은 도구 (선택)

- **[Obsidian](https://obsidian.md)** — 이 폴더를 보관함(vault)으로 열면 링크를 따라 읽고, 그래프 뷰로 연결 관계를 볼 수 있습니다. 첨부 파일 폴더는 이미 `raw/assets`로 설정해 두었습니다.
- **Obsidian Web Clipper** — 브라우저에서 웹 글을 마크다운으로 바로 `raw/`에 저장.
- **Dataview 플러그인** — 페이지 머리말(tags, type, updated 등)로 표를 만들어 조회.
- **Marp 플러그인** — 질의 결과를 슬라이드로.
- **Git** — 이 폴더는 git 저장소입니다. 변경 이력이 남습니다.

## 팁

- 자료는 한 번에 하나씩 넣고 Claude와 이야기하며 정리하면 품질이 가장 좋습니다.
- 위키는 쓸수록 쌓입니다. 질문에 대한 좋은 답도 위키에 다시 저장하세요.
- 규칙을 바꾸고 싶으면 Claude에게 "앞으로 ~하게 해 줘, 스키마에 반영해"라고 말하면 `CLAUDE.md`가 갱신됩니다.
