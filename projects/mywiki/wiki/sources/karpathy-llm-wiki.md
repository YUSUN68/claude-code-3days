# karpathy-llm-wiki

안드레이 카르파시가 GitHub Gist에 올린 짧은 "아이디어 문서"로, LLM이 개인 지식 위키를 직접 쓰고 관리하게 하는 방식을 제안한다. 구체적 구현보다 방향을 제시하는 데 목적이 있다.

## 핵심 내용

- 일반적인 검색 증강 생성(RAG)은 질문할 때마다 원본 조각을 다시 찾아 답을 새로 만들어 내므로 지식이 쌓이지 않는다.
- 대신 LLM이 자료를 읽을 때마다 요약, 개체 페이지, 개념 페이지, 상호 링크를 갱신해 **누적되는 위키**를 만든다.
- 구성은 세 층이다: 불변의 원본 자료, LLM이 소유하는 위키, 그리고 규칙을 적은 스키마 파일(Claude Code라면 `CLAUDE.md`).
- 주요 작업은 수집(ingest), 질의(query), 점검(lint) 세 가지다.
- `index.md`(내용 중심 목차)와 `log.md`(시간순 작업 기록) 두 특별 파일을 둔다.

## 주요 주장·데이터

- 자료 하나를 수집하면 10~15개 페이지가 함께 갱신될 수 있다.
- 출처 100개, 페이지 수백 개 규모까지는 별도 임베딩 검색 없이 `index.md`만으로 충분히 작동한다.
- 지식 관리에서 비싼 부분은 읽기나 생각이 아니라 장부 정리(링크, 갱신, 일관성 유지)이며, 이는 사람에게는 고되지만 LLM에게는 거의 공짜다.
- 좋은 질의 결과는 다시 위키 페이지로 저장해 지식을 복리로 쌓는다.
- 도구로 Obsidian(그래프 뷰, Web Clipper, Dataview, Marp), 로컬 마크다운 검색 도구 qmd, git을 권한다.
- 버니바 부시(Vannevar Bush)가 1945년에 구상한 메멕스(Memex)와 닮은 발상이라고 언급한다.
