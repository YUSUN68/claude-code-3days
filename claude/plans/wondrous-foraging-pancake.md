# 인테리어 소품 쇼핑몰 (Next.js + Supabase + Vercel)

## Context
빈 폴더(`C:\Users\student\Desktop\shopping`)에서 무드등·캔들·화병 등 인테리어 소품 쇼핑몰을 새로 만든다.
결정 사항: 기본 쇼핑몰 MVP / **이메일 로그인만, 소셜 로그인 제외** / 토스페이먼츠 **테스트 모드** 결제 / 기존 Supabase 프로젝트 `YUSUN1`(ref `wkdhpcyuuhnpoqdzhefp`, 서울 리전) / 따뜻한 미니멀 디자인.
YUSUN1에는 다른 앱의 테이블(`products`, `profiles`, `likes`, `chat_*`, `notifications`, `ledger_entries`)이 있으므로 **모든 새 테이블은 `shop_` 접두어**로 만들고 기존 테이블은 건드리지 않는다. `auth.users`는 공유한다.

## 1. 기능 상세

### 1-1. 공통 레이아웃
- **헤더**: 좌측 로고(텍스트 로고, 세리프체), 중앙 카테고리 메뉴(전체·무드등·캔들·화병·디퓨저·오브제·패브릭), 우측 검색 아이콘·로그인/마이페이지·장바구니(담긴 수량 배지). 스크롤하면 배경이 반투명 아이보리로 바뀌며 상단 고정.
- **모바일**: 햄버거 메뉴 → 왼쪽에서 열리는 드로어에 카테고리·로그인 링크.
- **푸터**: 상호/고객센터/배송·교환 안내 링크, 저작권 표기 (사업자 정보는 자리만 마련).
- 관리자로 로그인하면 헤더에 "관리자" 링크가 추가로 보임.

### 1-2. 홈 `/`
- **히어로**: 화면 너비 큰 이미지(따뜻한 조명의 거실 무드) + "당신의 공간에 온기를" 같은 카피 + "쇼핑하기" 버튼.
- **카테고리 바로가기**: 원형/라운드 썸네일 6개 가로 배치(모바일은 가로 스크롤).
- **신상품**: 최근 등록 8개 그리드.
- **베스트/추천**: 관리자가 `is_featured` 체크한 상품 4개.
- **브랜드 소개 띠 배너**: 짧은 문구 + 배경 사진.

### 1-3. 상품 목록 `/products?category=&sort=`
- 카테고리 탭(전체 포함)으로 필터, 정렬: 신상품순 / 낮은가격순 / 높은가격순.
- 상품 카드: 정사각 이미지(마우스 올리면 두 번째 이미지로 전환), 상품명, 가격(할인 시 원가 취소선 + 할인율 %), 품절이면 "SOLD OUT" 오버레이.
- 그리드: 데스크톱 4열 / 태블릿 3열 / 모바일 2열. 페이지당 12개, 하단 페이지네이션.
- 간단 검색: 헤더 검색창에서 상품명으로 검색 → `/products?q=` 결과.

### 1-4. 상품 상세 `/products/[slug]`
- 좌측: 메인 이미지 + 썸네일 리스트(클릭 시 교체). 우측: 카테고리, 상품명, 가격/할인, 짧은 설명, 수량 선택(+/−, 재고 초과 불가), **장바구니 담기** / **바로 구매** 버튼.
- 하단 탭: 상세 설명(텍스트), 배송/교환 안내(고정 문구).
- 같은 카테고리 상품 4개 "함께 보면 좋은 상품".
- 품절이면 버튼 비활성화 + "품절" 표시.

### 1-4-1. 선물 추천 `/gift`
- 헤더 메뉴와 홈에 "선물 추천" 진입점(홈에는 테마 카드 섹션 추가).
- **3단계 선택형 화면** (한 화면에서 칩 버튼으로 고르면 결과가 바로 갱신):
  1. **테마**: 집들이 / 생일 / 결혼·신혼 / 연인 / 감사·선생님 / 크리스마스·연말 / 나를 위한 선물
  2. **가격대**: ~2만원 / 2~5만원 / 5~10만원 / 10만원 이상
  3. **(선택) 카테고리**: 무드등·캔들·화병 등 — 비워두면 전체
- 결과: 조건에 맞는 상품 그리드 + 테마별 한 줄 추천 문구(예: 집들이 → "새 공간에 은은한 향과 빛을"). 정렬은 추천 상품(is_featured) 우선, 그다음 가격순.
- 결과가 없으면 가격대를 한 단계 넓혀 "비슷한 가격대 추천"을 보여줌.
- 선택한 조건은 URL(`/gift?theme=housewarming&price=20000-50000`)에 담겨 링크 공유 가능.
- 상품 상세 페이지에 해당 상품의 테마 배지(예: `#집들이선물` `#생일선물`) 표시, 클릭하면 그 테마로 `/gift` 이동.
- 관리자 상품 폼에서 테마를 체크박스로 지정.

### 1-5. 회원 (이메일만, 소셜 로그인 없음)
- **회원가입** `/signup`: 이름, 이메일, 비밀번호(8자 이상), 비밀번호 확인, 약관 동의 체크박스. Supabase 이메일 인증 메일 발송 → 링크 클릭 시 가입 완료. (개발 중에는 Supabase 설정에서 이메일 확인을 끄고 테스트할 수 있음)
- **로그인** `/login`: 이메일 + 비밀번호. 실패 시 한글 에러 메시지. 로그인 후 원래 보던 페이지로 이동.
- **비밀번호 찾기** (로그인 화면의 "비밀번호를 잊으셨나요?" 링크):
  1. `/forgot-password`: 가입한 이메일 입력 → Supabase `resetPasswordForEmail` 호출 → 재설정 링크 메일 발송. 가입 여부를 노출하지 않도록 항상 "메일을 보냈습니다" 안내(재전송은 60초 후 가능).
  2. 메일 링크 클릭 → `/auth/callback`에서 토큰을 세션으로 교환 → `/reset-password`로 이동.
  3. `/reset-password`: 새 비밀번호 + 확인 입력(8자 이상, 일치 검사) → `updateUser`로 변경 → "변경 완료" 후 로그인 상태로 홈 이동.
  - 링크 만료·잘못된 링크면 안내 문구와 "다시 요청하기" 버튼.
  - Supabase Auth의 Redirect URL에 `localhost:3000/auth/callback`과 Vercel 도메인을 등록, 메일 템플릿 문구는 한글로 변경.
- **로그아웃**: 헤더 메뉴.
- 가입하면 DB 트리거로 `shop_profiles` 행이 자동 생성(role=customer).

### 1-6. 장바구니 `/cart`
- 비로그인: 브라우저(localStorage)에 저장. 로그인하면 DB(`shop_cart_items`)로 자동 병합.
- 상품별 썸네일·이름·단가·수량 변경·삭제, 선택 삭제, 전체 합계.
- 배송비 규칙: **5만원 이상 무료, 미만 3,000원** (상수로 두어 쉽게 변경).
- "주문하기" → 비로그인이면 로그인 페이지로 보낸 뒤 돌아옴.

### 1-7. 주문·결제 `/checkout`
- 주문 상품 요약, 배송지 입력(받는 분, 연락처, 우편번호/주소 — 다음 우편번호 검색 팝업, 상세주소, 배송 메모). 마이페이지에 저장된 기본 배송지 자동 채움.
- **토스페이먼츠 결제위젯**(테스트 키): 카드·계좌이체·간편결제 선택 UI가 그대로 표시됨.
- 흐름: "결제하기" 클릭 → 서버에서 `pending` 주문 생성(금액은 서버가 DB 가격으로 다시 계산) → 토스 결제창 → `/checkout/success`에서 서버가 **주문 금액과 결제 금액을 대조**한 뒤 토스 승인 API 호출 → 주문 `paid`, 재고 차감, 장바구니 비움 → 주문 완료 화면(주문번호 표시).
- 실패/취소 시 `/checkout/fail`에서 사유 표시, 주문은 `cancelled`.
- 테스트 모드라 실제 돈은 나가지 않음.

### 1-8. 마이페이지 `/mypage`
- **주문 내역**: 주문일, 주문번호, 대표 상품명 외 N건, 금액, 상태 배지(결제완료/배송중/배송완료/취소).
- **주문 상세**: 상품 목록, 배송지, 결제 금액.
- **내 정보**: 이름·연락처·기본 배송지 수정, 비밀번호 변경.

### 1-9. 관리자 `/admin` (role=admin만 접근, 아니면 홈으로 이동)
- **상품 관리**: 목록(검색·카테고리 필터), 등록/수정 폼(이름, 카테고리, 가격, 할인가, 재고, 설명, 추천 여부, 노출 여부), 이미지 여러 장 업로드(Supabase Storage)·순서 변경·삭제.
- **주문 관리**: 주문 목록(상태 필터), 주문 상세, 상태 변경(결제완료 → 배송중 → 배송완료).
- **간단 요약**: 오늘 주문 수 / 오늘 매출 / 품절 상품 수 카드.
- 첫 관리자 계정은 가입 후 SQL로 role을 admin으로 바꿔 지정.

## 3. 기술 구성
- Next.js 15 (App Router, TypeScript, Server Components/Server Actions), Tailwind CSS
- `@supabase/ssr` + `@supabase/supabase-js`, `middleware.ts`로 세션 갱신 및 `/mypage`·`/checkout`·`/admin` 보호
- `@tosspayments/tosspayments-sdk` (결제위젯), 승인은 서버에서 `TOSS_SECRET_KEY`로 호출
- 배포: Vercel

### DB 스키마 (전부 RLS 활성화)
- `shop_categories` (id, slug, name, sort_order)
- `shop_products` (id, category_id, slug, name, description, price, sale_price, stock, images text[], is_featured, is_active, created_at)
- `shop_gift_themes` (id, slug, name, description, emoji/이미지, sort_order) — 테마 7개
- `shop_product_themes` (product_id, theme_id) — 상품↔테마 다대다. 가격대 필터는 `coalesce(sale_price, price)` 기준 범위 조회
- `shop_profiles` (id=auth.users.id, name, phone, zipcode, address1, address2, role) + 가입 트리거
- `shop_cart_items` (user_id, product_id, quantity, unique)
- `shop_orders` (id, user_id, order_no, status, items_amount, shipping_fee, total_amount, recipient, phone, zipcode, address1, address2, memo, payment_key, paid_at, created_at)
- `shop_order_items` (order_id, product_id, name·price 스냅샷, quantity)
- Storage 버킷 `shop-product-images` (공개 읽기, 관리자만 쓰기)
- RLS: 카테고리·노출 상품은 누구나 읽기 / 장바구니·주문·프로필은 본인만 / 관리 작업은 `shop_is_admin()`(security definer)일 때만
- 결제 승인·재고 차감은 서버 전용 로직(DB 함수 `shop_mark_order_paid`)으로 처리
- 시드: 아래 "샘플 데이터" 참고

### 샘플 데이터 (시드 SQL 파일 `supabase/seed/shop_seed.sql`로도 보관)
카테고리 6개 × **각 8개 = 상품 48개**. 카테고리마다 가격대가 고르게 퍼지도록(~2만 / 2~5만 / 5~10만 / 10만+) 구성하고, 일부는 할인가·품절·추천 상품으로 지정. 각 상품에 선물 테마 1~3개 연결.
- **무드등**: 버섯 무드등, 패브릭 플리츠 스탠드, 유리 돔 LED 램프, 우드 베이스 테이블 램프, 무선 충전 무드등, 달 조명, 라탄 펜던트, 알루미늄 클립 램프
- **캔들**: 소이 캔들(우디/플로럴/시트러스), 콘크리트 용기 캔들, 필러 캔들 3종 세트, 테이퍼 캔들 2P, 캔들 워머 + 캔들 세트, 티라이트 24P, 크리스마스 한정 캔들, 캔들 스너퍼 세트
- **화병**: 미니 세라믹 화병, 유리 버블 화병, 빈티지 도자기 화병, 대형 테라코타 베이스, 플라워 프로그 세트, 드라이플라워 + 화병 세트, 손잡이 저그 화병, 웨이브 아크릴 화병
- **디퓨저**: 리드 디퓨저 200ml(향 여러 종), 차량용 디퓨저, 세라믹 오일 버너, 초음파 디퓨저, 디퓨저 리필, 룸스프레이, 사쉐 3P, 집들이 디퓨저 기프트 세트
- **오브제**: 석고 조각 오브제, 원목 트레이, 대리석 북엔드, 미니 액자, 세라믹 인센스 홀더, 데스크 시계, 모빌, 캔들 홀더 오브제
- **패브릭**: 린넨 쿠션 커버, 니트 블랭킷, 테이블 러너, 코튼 티매트 2P, 패브릭 포스터, 라탄 바구니, 극세사 러그, 린넨 앞치마

상품마다 2~3문장 설명, 2장 이미지(Unsplash 무료 이미지 URL — 실제 렌더링 확인 후 깨지는 링크는 교체), 재고 0~50 랜덤.
